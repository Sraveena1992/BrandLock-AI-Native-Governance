# 🛡️ BrandLock - AI-Native Brand Governance Platform

BrandLock is an intelligent agentic AI platform designed for modern organizations to review, validate, and govern all multi-channel content before publication. Built for the Inkloom AI Hackathon / Founding Builder Program.

## 🚀 Core Features
- **Multi-Agent AI Swarm:** Specialized parallel agents checking Tone, Terminology, Fact/Claims, Visual Assets, Accessibility, and Confidentiality.
- **Explainable Citations:** Flags issues mapped directly to organization guideline pages and chunks.
- **1-Click AI Auto-Fixes:** Context-aware suggestions that preserve creator intent.
- **Collaborative Workflows:** Role-based approvals (Creator, Manager, Legal) with version history and inline comments.
- **Isolated Tenant Privacy:** Secure RAG architecture using ChromaDB.

## 🛠️ Tech Stack
- **Frontend:** Next.js 14, TypeScript, Tailwind CSS, Shadcn UI
- **Backend / AI:** FastAPI (Python), OpenAI APIs, ChromaDB, GPT-4o Vision
